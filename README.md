# よむたんけん（試作）

1・2年生の国語「読むこと」の学習アプリ試作版です。

## 学習の流れ

1. 文（ものがたり／せつめい）を読みます
2. もんだいに3つの選択肢から答えます
3. 答えがどこに書いてあるか、その文を本文からタップで探します（答えと文の両方が合って初めて「自力でできた」になります）。文をタップする場面では、指さしの手がアニメーションで促します
4. つまずいた もんだいは端末内に記録され、「とっくん」で再挑戦して、自力でできたら記録が消えます

## 内容

- 1年生：物語8本・説明6本（ひらがな中心）
- 2年生：物語8本・説明6本（漢字にはふりがな、ON/OFF可）
- 各文6〜8問、全28本・200問（文章はすべてオリジナル）。1回の学習では、その中から4問がランダムに出るので、同じ文でも毎回ちがう問題に挑戦できます
- 文をタップする場面では、大きな指さしの手が文の中心に約2秒だけアニメーション表示され、タップできる文の光り方も約2秒で止まります
- ホームの文章カードが増えたら、カードの部分だけがスクロールします

## 技術

- HTML/CSS/JavaScript の単一ファイル、データ保存は localStorage（外部API不使用）
- 演出と音は共通基盤 edu-effects / sounds-recipe-、ナビキャラ画像は navi-character- を使用
- 保存キー：yomuTanken.mistakes.v1 / stats.v1 / settings.v1
- とっくんの記録は「文章ID＋問題の文」で保持します（問題を追加・並べ替えても記録がずれません。旧形式の記録は読み込み時に自動で移行します）

## 文章データ（texts.json）の作り方

文章と問題は `texts.json` に分離してあります。他のAIや人が文章を増やすときは、このファイルだけを編集してください。追加したら `python3 tools/validate_texts.py texts.json` で検証できます。

### 1つの文章の形式

```json
{
  "id": "g1-t8",
  "grade": 1,
  "kind": "ものがたり",
  "title": "タイトル",
  "sentences": ["文1。", "文2。"],
  "questions": [
    { "q": "問題文", "choices": ["正解", "まちがい1", "まちがい2"], "answer": "正解", "evidence": 0, "explain": "解説（書いてある文を短く示す）" }
  ],
  "order": [0, 1, 2, 3]
}
```

- `id`：`g{学年}-t{連番}`。既存と重複させない。
- `kind`：「ものがたり」か「せつめい」。
- `sentences`：本文。1文ずつ配列に入れる（根拠タップの単位になります）。
- `questions`：1つの文章に6〜8問を収録しています。問いは1・2年生ともにひらがなで書き、1回の学習では4問がランダムに出ます。新しい問題には、理由・変化・原因と結果・気持ちなど、文の情報をつないで考える問いも含めています。
- `answer`：必ず `choices` の中の文字列と完全一致させる。
- `evidence`：答えが書いてある文の番号（0から数える）。
- 並べ替え問題（任意）：問題に `"format": "sort"` を付けると、その問題は選択式ではなく「カードを順番にタップする」問題になります。`cards` に短いカード文を**正しい順番で**並べ、`evidence` には各カードに対応する本文の文番号を同じ順で書きます。`choices` と `answer` は不要です。
- `order`（任意）：「じゅんばん ならべ」で使う文の番号を、物語の順番に並べたもの。4つが目安。付けた文章だけ、読む画面にボタンが出ます。**物語だけに付けます**（説明文は文の順番が1つに決まらないので付けません）。

### 低学年向けの問題づくり・見直しの観点

- 1・2年生とも、問いはひらがなで書く。問いを読む負担を減らし、本文を読んで考えることに集中できるようにする。
- 1年生向けの選択肢・解説は、ひらがなを中心にし、習っていない漢字を使わない。
- 2年生向けの選択肢・解説は、学年で習う漢字を基本とし、それ以外の漢字には読みを付ける。
- 問いは一度読んで意味が分かる短い言い方にする。「原因と結果」などの抽象的な用語を、子ども向けの問いにそのまま使わない。
- 正解は本文の言葉や出来事に結び付け、根拠となる文を子どもが自分で見つけられるようにする。
- 同じ文章の中で、同じ内容を聞く問題をくり返さない。人物・場所・行動・様子・順序・理由など、本文にある別の情報を生かす。
- 推測を問う場合は、本文の情報を手がかりに考えられる範囲にとどめ、本文にない知識を知らないと解けない問題にしない。
- 選択肢は短く、正解だけが不自然に長くならないようにする。まちがいの選択肢も、低学年の子どもが意味を理解できる言葉にする。
- 解説は、正解の理由を本文の言葉に戻って短く説明する。

### 漢字とふりがなのルール

- 漢字の読みは `漢字《よみ》` と書きます（例：`学校《がっこう》`）。ふりがなONのときルビになり、OFFでは漢字だけになります。
- 1年生の文章：ひらがな中心。漢字は1年生で習う字だけにし、ふりがなは付けません。
- 2年生の文章：漢字には必ず `《よみ》` を付けます。3年生以上で習う漢字は使わないのが原則です。
- 文章は必ずオリジナル（教科書の文章は使わない）。

### とっくん記録との関係

間違いの記録は「文章ID＋問題文」で保持しています。公開済みの問題の `q`（問題文）を書き換えると、その問題の記録だけが消えます（他の記録は無事です）。文章の追加や、問題の末尾への追加は安全です。
