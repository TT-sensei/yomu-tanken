# よむたんけん（試作）

1・2年生の国語「読むこと」の学習アプリ試作版です。

## 学習の流れ

1. 文（ものがたり／せつめい）を読みます
2. もんだいに3つの選択肢から答えます
3. 答えがどこに書いてあるか、その文を本文からタップで探します（答えと文の両方が合って初めて「自力でできた」になります）。文をタップする場面では、指さしの手がアニメーションで促します
4. つまずいた もんだいは端末内に記録され、「とっくん」で再挑戦して、自力でできたら記録が消えます

## 内容

- 1年生：物語3本・説明2本（ひらがな中心）
- 2年生：物語3本・説明2本（漢字にはふりがな、ON/OFF可）
- 各文6問、全10本・60問（文章はすべてオリジナル）。1回の学習では、その中から4問がランダムに出るので、同じ文でも毎回ちがう問題に挑戦できます

## 技術

- HTML/CSS/JavaScript の単一ファイル、データ保存は localStorage（外部API不使用）
- 演出と音は共通基盤 edu-effects / sounds-recipe-、ナビキャラ画像は navi-character- を使用
- 保存キー：yomuTanken.mistakes.v1 / stats.v1 / settings.v1
